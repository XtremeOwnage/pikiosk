Activity

    Rotations

    A rotation shows views in turn. Showing something for a set time pauses the rotation, which carries on afterwards; showing something with no time stops it until you resume it.

    Library

    Playback

    Home Assistant can also use the kiosk as a speaker: it shows up as a DLNA media player (Settings → Devices & services → DLNA Digital Media Renderer), so TTS and media can be sent to it directly.

    Casting

    AirPlay:

    iPhones, iPads and Macs on the same network can mirror their screen or play video and music here (Control Center → Screen Mirroring). The cast covers the screen until the device disconnects. Android phones can send media over DLNA with an app such as BubbleUPnP.

    Views

    A view is a named web page or stream. MQTT, the API and Home Assistant select views by name. Untick a view to skip it in rotations; it can still be shown directly.
